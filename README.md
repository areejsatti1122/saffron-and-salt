# Saffron & Salt - Restaurant Website

Web Technologies Assignment 1 (CLO1)
Made by **Areej Zeb Satti** (052-SP24-24255), BS Computer Science, Iqra University

This is a 4 page responsive website for a restaurant (not a real business). It is made with HTML5, CSS3 and Bootstrap 5.

## Pages
- `index.html` - Home (carousel, info strip, dish cards)
- `about.html` - About (our story, lists, gallery)
- `services.html` - Services (service boxes, menu table, catering modal)
- `contact.html` - Contact (booking form, timings table)

## Folders
- `css/` - my stylesheet (`style.css`), Bootstrap and Bootstrap Icons
- `fonts/` - Merriweather and Open Sans
- `images/` - images used in the website
- `js/` - Bootstrap JS and `main.js` (form validation)

## How to run
Open `index.html` in Chrome, Edge or Firefox. No installation is needed.

## Used
- Bootstrap 5.3 and Bootstrap Icons (https://getbootstrap.com)
- Merriweather and Open Sans fonts (Google Fonts, via Fontsource)
